# Chatfenster unter Windows

Gilt für Windows 10 und 11 (64 Bit). Du brauchst **keine Adminrechte**.
Zurück zur [Übersicht](README.md).

> Für Windows gibt es auch die offizielle WhatsApp-App im Microsoft Store.
> Chatfenster ist die Alternative, die unter Windows und Linux gleich aussieht
> und sich gleich bedienen lässt.

## Chatfenster installieren

1. Lade den Installer herunter:
   **[ChatfensterSetup.exe](https://github.com/CrazyJimPro/chatfenster/releases/latest/download/ChatfensterSetup.exe)**
   (ca. 100 MB, landet in deinem Ordner **Downloads**).
2. Falls der Browser meldet, die Datei werde *nicht häufig heruntergeladen*:
   in der Download-Liste auf **⋯** → **Behalten** → **Trotzdem behalten**
   klicken.
3. Doppelklick auf **ChatfensterSetup.exe**.
4. Wahrscheinlich erscheint ein blaues Fenster **„Der Computer wurde durch
   Windows geschützt“**. Das liegt daran, dass der Installer nicht bei
   Microsoft signiert ist. Klicke auf **Weitere Informationen** und dann auf
   **Trotzdem ausführen**.
5. Ein kurzer Fortschrittsbalken läuft durch, eine Rückfrage gibt es nicht.
   Danach startet Chatfenster von selbst.
6. Ab jetzt findest du **Chatfenster** im Startmenü und als Verknüpfung auf
   dem Desktop.

## Mit dem Handy anmelden

Das musst du nur beim ersten Start machen, danach bleibst du angemeldet.

1. Starte **Chatfenster**.
2. Im Fenster erscheint **„Zum Anmelden scannen“** mit einem QR-Code.
3. Auf dem Handy: WhatsApp öffnen → **Einstellungen** (iPhone) bzw. **⋮**
   (Android) → **Verknüpfte Geräte** → **Gerät hinzufügen**.
4. Halte die Handykamera auf den QR-Code. Nach ein paar Sekunden erscheinen
   deine Chats.

Den Haken **„In diesem Browser angemeldet bleiben“** unter dem QR-Code drin
lassen, sonst musst du bei jedem Start neu scannen.

## Chatfenster benutzen

- **Menüleiste einblenden:** Die Leiste ist versteckt. Drück kurz `Alt`, dann
  erscheinen **Datei, Bearbeiten, Ansicht, Einstellungen, Hilfe**.
- **Neu laden**, falls etwas hängt: `F5`.
- **Links** aus Chats öffnen sich in deinem normalen Browser.
- **Dateien/Bilder herunterladen:** landen direkt in **Downloads**. Der
  Fortschritt läuft grün über das Symbol in der Taskleiste, danach zeigt ein
  Hinweis den Dateinamen. **„Ordner öffnen“** springt hin.
- **Rechtschreibung:** rot unterstrichene Wörter rechts anklicken, einen
  Vorschlag wählen oder **„… zum Wörterbuch hinzufügen“**.
- **Beenden:** `Strg` + `Q`. Das **X** versteckt das Fenster nur, siehe
  [Das Symbol im Infobereich](#das-symbol-im-infobereich).

## Das Symbol im Infobereich

Solange Chatfenster läuft, liegt sein Symbol unten rechts neben der Uhr. Hast du
ungelesene Chats, zeigt ein **roter Kreis mit Zahl** an, wie viele es sind
(ab 10 steht dort „9+“). Die Zahl erscheint auch am Symbol in der Taskleiste.

- **Klick auf das Symbol:** holt das Fenster nach vorn.
- **Rechtsklick:** Menü mit **Chatfenster öffnen** und **Beenden**.

Windows versteckt neue Symbole gern hinter dem **Pfeil ^** neben der Uhr. Damit
es immer sichtbar ist, zieh das Symbol von dort mit der Maus in die Leiste.

**Fenster schließen heißt jetzt verstecken:** Mit dem **X** verschwindet nur das
Fenster. Chatfenster läuft im Hintergrund weiter, du bekommst also weiter
Benachrichtigungen. Beim allerersten Schließen fragt Chatfenster, ob du das so
möchtest (**Weiterlaufen** oder **Beenden**).

**Ganz beenden** kannst du es so:

- `Strg` + `Q` im Fenster, oder
- Rechtsklick auf das Symbol → **Beenden**.

**Lieber wie früher?** `Alt` drücken → **Einstellungen** → Haken bei **Beim
Schließen im Infobereich weiterlaufen** entfernen. Dann beendet das **X**
Chatfenster wieder ganz.

## Automatisch starten beim Anmelden

1. In Chatfenster kurz `Alt` drücken, dann erscheint die Menüleiste.
2. Menü **Einstellungen** → Haken bei **Beim Anmelden automatisch starten** setzen.
3. Möchtest du beim Anmelden kein Fenster sehen: Zusätzlich den Haken bei
   **Dabei nur als Symbol starten, ohne Fenster** setzen. Chatfenster liegt dann
   nur als Symbol neben der Uhr. Ein Klick darauf öffnet das Fenster.

Beim nächsten Anmelden startet Chatfenster von selbst. Zum Abschalten
denselben Haken wieder entfernen.

Der Eintrag erscheint auch unter **Start** → **Einstellungen** → **Apps** →
**Autostart** und im Task-Manager. Wenn du ihn dort abschaltest, ist auch der
Haken in Chatfenster weg. Beim Aktualisieren bleibt der Autostart erhalten, beim
Deinstallieren wird er entfernt.
## Benachrichtigungen einstellen

Bei neuen Nachrichten erscheint unten rechts über der Uhr eine Benachrichtigung mit Name und
Nachrichtentext, auch wenn Chatfenster im Hintergrund liegt.
**Ein Klick darauf** holt Chatfenster nach vorn und öffnet den Chat.

1. In Chatfenster kurz `Alt` drücken, dann erscheint die Menüleiste.
2. Menü **Einstellungen** öffnen. Dort gibt es drei Punkte:
   - **Benachrichtigungen anzeigen**: Haken weg = gar keine Benachrichtigungen mehr.
   - **Nachrichtentext in Benachrichtigungen zeigen**: Haken weg = es erscheint
     nur noch „Neue Nachricht“, ohne Absender, Text und Profilbild. Gut, wenn
     andere auf deinen Bildschirm schauen können.
   - **Test-Benachrichtigung senden**: zeigt sofort eine Probe-Benachrichtigung.
     Damit prüfst du, ob Windows sie durchlässt.
3. Die Einstellungen gelten sofort und bleiben nach einem Neustart erhalten.

Kommt bei der Test-Benachrichtigung nichts an:

1. **Start** → **Einstellungen** → **System** → **Benachrichtigungen**.
2. Ganz oben muss **Benachrichtigungen** eingeschaltet sein.
3. **Nicht stören** (Windows 11) bzw. **Benachrichtigungsassistent /
   Fokus-Assistent** (Windows 10) muss aus sein.
4. Weiter unten in der App-Liste **Chatfenster** suchen und einschalten.
   Chatfenster taucht dort erst auf, nachdem es einmal eine Benachrichtigung
   gezeigt hat, also vorher die Test-Benachrichtigung senden.

Ton und Benachrichtigungen lassen sich zusätzlich in WhatsApp selbst einstellen
(in WhatsApp Web unter dessen eigenen Einstellungen → Benachrichtigungen). Was
du dort abschaltest, kommt in Chatfenster auch nicht an.

## Auf eine neue Version aktualisieren

1. Prüfen, ob es eine neue Version gibt: in Chatfenster `Alt` drücken →
   **Hilfe → Nach Updates suchen**.
2. Wenn ja: **Release-Seite öffnen** klicken (oder den Link aus
   [Installieren, Schritt 1](#chatfenster-installieren) benutzen) und
   **ChatfensterSetup.exe** herunterladen.
3. **Chatfenster beenden** (`Strg` + `Q`, das **X** reicht nicht).
4. Die neue **ChatfensterSetup.exe** ausführen, wie bei der Installation
   (Schritte 3 bis 5). Sie ersetzt die alte Version, deine Anmeldung bleibt
   erhalten.

## Chatfenster deinstallieren

1. **Start** → **Einstellungen** → **Apps** → **Installierte Apps** (Windows 10:
   **Apps & Features**).
2. In der Liste **Chatfenster** suchen → **⋯** → **Deinstallieren** →
   nochmals **Deinstallieren**.
3. Deine Anmeldung und Einstellungen bleiben dabei erhalten. Wenn du auch die
   löschen willst: `Windows-Taste` + `R` drücken, `%APPDATA%` eingeben,
   `Enter`, und dort den Ordner **Chatfenster** löschen.

Tipp: Auf dem Handy unter **Verknüpfte Geräte** kannst du das Gerät danach
auch dort abmelden.

## Wenn etwas nicht klappt

**Wo stehen Fehlermeldungen?**

- Logbuch: `%APPDATA%\Chatfenster\logs\chatfenster.log`
  (schnell erreichbar über `Alt` → **Hilfe → Logordner öffnen**)

**Häufige Fälle**

| Was passiert                                   | Was hilft |
|-----------------------------------------------|-----------|
| „Der Computer wurde durch Windows geschützt“  | Normal bei nicht signierten Programmen: **Weitere Informationen** → **Trotzdem ausführen**. |
| Virenscanner hält den Installer fest          | Datei im Virenscanner freigeben oder später erneut herunterladen. Den Quellcode kannst du auf GitHub einsehen. |
| Fenster bleibt leer / „Verbindung wird hergestellt …“ | Internet prüfen. Chatfenster versucht es alle 10 Sekunden selbst neu. `F5` lädt sofort neu. |
| QR-Code wird nach dem Scannen nicht angenommen | Handy und PC brauchen Internet. Am Handy unter **Verknüpfte Geräte** prüfen, ob schon 4 Geräte verknüpft sind (das ist das Maximum). |
| Nach jedem Start wieder QR-Code               | Beim Scannen war der Haken **„In diesem Browser angemeldet bleiben“** aus. Einmal mit Haken neu scannen. |
| Ich will komplett neu anfangen                 | Chatfenster beenden (`Strg` + `Q`), Ordner `%APPDATA%\Chatfenster` löschen, neu starten und neu scannen. |
| Keine Benachrichtigungen                        | Siehe [Benachrichtigungen einstellen](#benachrichtigungen-einstellen): Haken unter **Einstellungen** prüfen, Test-Benachrichtigung senden, Windows-Einstellungen prüfen. |
| Fenster ist weg, Programm läuft noch            | Das **X** versteckt nur. Klick auf das Symbol neben der Uhr (eventuell hinter dem Pfeil **^**) oder Chatfenster aus dem Startmenü starten holt es zurück. |
| Startet beim Anmelden nicht von selbst          | Unter **Einstellungen** den Haken **Beim Anmelden automatisch starten** prüfen. Unter **Start** → **Einstellungen** → **Apps** → **Autostart** muss **Chatfenster** eingeschaltet sein. |
| Installer meldet, Chatfenster laufe noch      | Chatfenster beenden (`Strg` + `Q` oder Rechtsklick auf das Symbol → **Beenden**). Wenn es hängt: Task-Manager (`Strg` + `Umschalt` + `Esc`) → **Chatfenster** → **Task beenden**. |

**Wo liegt was?**

| Was                         | Ort |
|-----------------------------|-----|
| Programm                    | `%LOCALAPPDATA%\Programs\Chatfenster` |
| Anmeldung, Einstellungen    | `%APPDATA%\Chatfenster` |
| Logbuch                     | `%APPDATA%\Chatfenster\logs\chatfenster.log` |
| Autostart-Eintrag (falls an) | Registry: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, Wert `de.crazyjimpro.chatfenster` |
